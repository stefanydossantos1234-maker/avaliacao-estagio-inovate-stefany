Avaliação Técnica - Estágio INOVATE

&#x20;Descrição:

Projeto desenvolvido para atender aos requisitos da avaliação técnica para estágio.



A solução está dividida em duas partes:

Parte 1: Lógica de Programação

Parte 2: Consultas SQL

Tecnologias Utilizadas:

&#x20;Python 3

SQL



Estrutura do Projeto:

avaliacao-estagio-inovate/

* &#x20;main.py
* &#x20;consultas.sql
* &#x20;README.md
* .gitignore



Como Executar:

1- Instale o Python 3.

2- Abra o terminal na pasta do projeto.

3- Execute o comando:



python main.py

&#x20;Funcionalidades:

* &#x20;Cadastro de produtos.
* &#x20;Cálculo do valor total da compra.
* Validação de quantidade e preço.
* Aplicação de desconto de 10% para compras acima de R$ 100,00.
* Consultas SQL para análise de compras e produtos.
